# Протоколер

AI-ассистент для составления протоколов совещаний. Пользователь загружает
расшифровку встречи, в диалоге уточняет недостающее — участников, договор,
сроки, — и получает готовый протокол в Word по корпоративному шаблону и
регламенту.

Всё работает внутри вашей инфраструктуры: приложение, база данных и языковая
модель разворачиваются на ваших серверах, данные наружу не уходят.

## Возможности

- **Протокол из расшифровки.** Загрузка `.txt`, `.docx`, `.pdf`. Ассистент
  находит повестку, участников, обсуждение и решения, а пробелы помечает
  «⚠️ требует уточнения» вместо того, чтобы их выдумывать.
- **Диалог перед сборкой.** До генерации документа ассистент уточняет шапку,
  договор и участников — то, чего в расшифровке нет.
- **Протокол в реальном времени.** Документ собирается в правой панели по ходу
  генерации, его можно править вручную.
- **Точечные правки.** «Поменяй должность Иванова» меняет одно место, а не
  пересобирает весь документ.
- **DOCX по корпоративному шаблону.** Шрифты, поля, колонтитулы с логотипом и
  нумерация берутся из самого шаблона — без ручной вёрстки.
- **Папки проектов.** Общие инструкции и источники для группы чатов, поиск по
  документам источников (RAG).
- **Администрирование.** Самостоятельной регистрации нет: пользователей заводит
  администратор на `/admin`.
- **Глоссарий терминов.** Единые написания терминов и сокращений во всех
  протоколах.

## Как это устроено

```
 Браузер ──► web (Next.js) ──► LLM-сервер (OpenAI-совместимый: vLLM / Ollama)
                  │
                  ├──► SurrealDB      пользователи, чаты, протоколы, папки
                  └──► rag-api        поиск по источникам папок (опционально)
```

| Компонент | Технология | Обязателен |
|---|---|---|
| `web` | Next.js 16, React 19, Vercel AI SDK 5, Node.js 22 | да |
| `surrealdb` | SurrealDB 2.6 | да |
| LLM-сервер | любой OpenAI-совместимый API: vLLM, Ollama, шлюз | да |
| `rag-api` | Python, FastAPI, LightRAG, MinerU | нет — только для источников папок |

Языковая модель в комплект не входит: подключается ваш LLM-сервер или
встроенный контейнер `ollama` (нужна видеокарта NVIDIA).

## Развёртывание

**Полная инструкция: [deploy/contour/README.md](deploy/contour/README.md)** —
требования к серверу, сборка образов для сети без интернета, первый запуск,
перенос данных, бэкапы, обновление и разбор неполадок.

Быстрый старт на сервере с Docker Engine 24+ и Compose v2:

```bash
cp deploy/contour/env.contour.example .env
nano .env                      # пароль БД, секрет сессий, логины админов, адрес LLM
docker compose up -d           # web + surrealdb
curl -s http://127.0.0.1:3000/api/health/db
```

Опциональные части включаются профилями:

```bash
docker compose --profile rag up -d       # + rag-api (источники папок)
docker compose --profile ollama up -d    # + своя Ollama, если LLM-сервера нет
```

Затем откройте сайт, нажмите «Первый вход администратора» и зарегистрируйте
логин из `ADMIN_USERNAMES`.

По умолчанию порты слушают только `127.0.0.1`. Наружу приложение публикуется
через reverse-proxy с TLS (nginx и т.п.) с `proxy_buffering off` — протокол
стримится по SSE.

## Требования к языковой модели

Это главное, что определяет качество и надёжность работы.

- **API.** OpenAI-совместимый `/v1/chat/completions` и `/v1/models`. Проверено
  на vLLM и Ollama.
- **Модель.** Класс Qwen3 на 14–30 млрд параметров. Рабочий стенд сейчас
  готовит протоколы на `Qwen3.8-27B`; шаблон `.env` по умолчанию предлагает
  `qwen3:14b` для встроенной Ollama.
- **Окно контекста — минимум 32 768 токенов, для длинных встреч 65 536.**
  Промпт полуторачасовой расшифровки занимает около 32 тысяч токенов, и при
  окне 32 768 на сам протокол места уже не остаётся. Задаётся двумя
  переменными, которые надо менять вместе — подробности прямо в
  [шаблоне .env](deploy/contour/env.contour.example).
- **Стриминг.** Если LLM-сервер отвечает JSON на `stream: true` вместо SSE,
  поставьте `LLM_FORCE_NONSTREAM=true`.

Имя модели и окно vLLM приложение узнаёт само из `/v1/models`, поэтому
переименование модели на сервере не требует правки настроек.

## Настройка

Все параметры задаются в `.env`. Полный шаблон с пояснениями —
[deploy/contour/env.contour.example](deploy/contour/env.contour.example).

| Переменная | Назначение |
|---|---|
| `SURREALDB_PASSWORD` | пароль БД; задаётся до первого запуска |
| `SESSION_SECRET` | подпись сессий: `openssl rand -hex 32` |
| `ADMIN_USERNAMES` | логины администраторов через запятую |
| `OLLAMA_BASE_URL`, `OLLAMA_API_KEY` | адрес и ключ LLM-сервера (название историческое — подходит любой OpenAI-совместимый) |
| `OLLAMA_CONTEXT_LENGTH`, `LLM_MAX_MODEL_LEN` | окно контекста модели — менять вместе |
| `RAG_API_URL` | адрес `rag-api`; пусто — RAG выключен |

Правила составления протокола (регламент) — в
[lib/prompts/regulation.ts](lib/prompts/regulation.ts). Корпоративный шаблон
документа — [lib/docx-template/assets/protocol-template.docx](lib/docx-template/assets/protocol-template.docx);
исходник для его пересборки — `Шаблон протокола чистый.docx` в корне,
команда `npm run build:protocol-template`.

## Разработка

Нужны Node.js 22 и запущенная SurrealDB.

```bash
npm ci
cp .env.example .env           # и заполнить
npm run dev                    # http://localhost:3000
```

| Команда | Что делает |
|---|---|
| `npm test` | модульные тесты (Jest) |
| `npx tsc --noEmit` | проверка типов |
| `npm run build` | production-сборка |
| `npm run lint` | Biome |
| `npm run build:protocol-template` | пересобрать шаблон DOCX из исходника |
| `npm run preview:protocol` | собрать образец протокола и отрендерить его в PNG для сверки с шаблоном (нужен LibreOffice) |

Вне Docker адрес БД — `ws://127.0.0.1:8000/rpc`: хост `surrealdb` существует
только внутри compose.

## Структура репозитория

```
app/                    Next.js: страницы и API-роуты
  api/chat/agents/      агенты: диалог, сборка протокола, точечные правки
components/             интерфейс: чат, панель документа, папки, админка
lib/
  prompts/              системные промпты и регламент
  docx-template/        сборка DOCX по корпоративному шаблону
  schemas/              схема протокола (Zod)
  protocol-guards.ts    детерминированная постобработка протокола
  getPromt.ts           подключение и схема SurrealDB
data/                   глоссарий терминов
rag-api/                сервис поиска по документам (Python)
deploy/contour/         развёртывание в контуре компании
scripts/contour/        сборка комплекта образов, экспорт/импорт/бэкап БД
```
