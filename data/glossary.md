# Глоссарий замен для протокола

Формат: `слово -> замена` (пустая замена — слово удаляется из текста).
Одна строка — одно правило; словосочетания тоже можно. Файл можно править
руками; ИИ дополняет его сам, если попросить в чате («не пиши X, пиши Y»).
Замены применяются в двух местах: как контекст для модели (она пишет сразу
правильно, в нужном падеже) и детерминированной подстановкой перед выводом
документа (гарантия, что запрещённое слово не проскочит).

- доделывается -> находится в стадии завершения
- доделано -> завершено
- боли -> проблемные аспекты
- болевые точки -> проблемные аспекты
- тайм-коды -> отметки времени
- локальность -> локальная обработка данных
- пинговать -> направить запрос
- стукнуть -> уведомить
- скинуть -> направить
- задача висит -> выполнение задачи приостановлено
- ТЗ -> техническое задание
